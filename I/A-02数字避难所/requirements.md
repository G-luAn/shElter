# 需求文档

## 一、项目背景

### 1.1 问题现状

当前主流社交平台（如贴吧、论坛、Discord）普遍存在以下问题：

- **准入门槛低** — 任何人都可以随意加入，社群质量参差不齐
- **审核机制缺失** — 缺乏有效的筛选机制，导致低质内容泛滥
- **商业化混乱** — 平台与社群主利益分配不清晰
- **隐私保护不足** — 用户数据被过度收集和利用

### 1.2 市场需求

- 小众社群需要**专属的私密空间**，与大众保持距离
- 社群创始人需要**高效的审核工具**，筛选真正志同道合的成员
- 社群运营需要**可持续的商业模式**，支撑长期发展

---

## 二、项目定位

### 2.1 产品定位

数字避难所是一个**小众社群托管平台**，为各类小众兴趣群体提供私有化、可定制的社群空间。

### 2.2 目标用户

| 用户类型 | 描述 |
|---------|------|
| 社群创始人 | 有明确社群主题和愿景，希望建立高门槛、高质量社群 |
| 社群成员 | 追求深度交流，渴望找到真正志同道合的伙伴 |
| 小众文化爱好者 | 希望在安全、私密的环境中探索特定兴趣 |

### 2.3 核心价值主张

- **严格准入** — 每个社群可自定义入门审核机制
- **隐私保护** — 用户数据最小化收集，尊重用户隐私
- **利益共享** — 平台与社群创始人共同受益

---

## 三、功能需求

### 3.1 核心功能

#### F1：社群创建与管理

- 社群创始人可自主创建社群，设置社群名称、简介、主题标签
- 支持设置社群头像、封面图、公告
- 提供社群基本设置页面，支持资料修改

#### F2：准入审核机制

- **入门问题设置** — 社群创始人可自定义 1-5 道入门问题
- **答题审核** — 用户申请加入需回答入门问题
- **审核状态追踪** — 显示待审核、已通过、已拒绝等状态
- **审核结果通知** — 通过站内信或邮件通知申请人

#### F3：成员管理体系

- 成员列表管理（查看、移除违规成员）
- 成员角色划分（创始人、管理员、普通成员）
- 禁言、踢出等管理功能

#### F4：内容发布与互动

- 支持发布帖子、评论、点赞
- 支持上传图片、文件
- 支持话题标签分类

#### F5：收费与商业模式（规划中）

| 收费模式 | 说明 | 状态 |
|---------|------|------|
| 入门费 | 社群创始人设定加入社群的入门费用 | 规划中 |
| 平台抽成 | 平台从入门费中抽取一定比例 | 规划中 |
| 广告分成 | 社群内展示广告，成员与平台分成 | 探索中 |
| 其他方式 | 更多商业模式待讨论 | 待定 |

### 3.2 非功能需求

#### 性能需求

- 页面加载时间不超过 3 秒
- 支持至少 1000 人同时在线的单一社群

#### 安全需求

- 用户密码加密存储
- 敏感操作需二次验证
- 数据传输使用 HTTPS 加密

#### 隐私需求

- 最小化收集用户信息
- 支持用户删除个人数据
- 不默认追踪用户行为

---

## 四、用户旅程

### 4.1 社群创始人

```
注册账号 → 验证身份 → 创建社群 → 设置入门问题 → 设定收费（可选）
→ 等待用户申请 → 审核申请 → 管理社群内容与成员
```

### 4.2 社群成员

```
注册账号 → 浏览社群列表 → 选择感兴趣的社群 → 回答入门问题
→ 等待审核结果 → 加入社群 → 参与讨论
```

---

## 五、成功指标

| 指标 | 目标 | 说明 |
|-----|------|------|
| 社群数量 | 第一年达到 100 个 | 验证市场需求 |
| 平均成员留存率 | 70% | 衡量社群活跃度 |
| 审核通过率 | 40%-60% | 平衡准入门槛与用户增长 |
| 用户满意度 | 4.5/5 分以上 | 持续迭代改进 |
