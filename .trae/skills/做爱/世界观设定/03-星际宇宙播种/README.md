## 背景故事

公元3045年，人类文明扩展到了整个银河系。然而，大多数新发现的星球都不适合人类生存，除非经过特殊的"改造"——用精液中的基因信息来重塑星球的大气层和生态系统。

银河联邦成立了"宇宙播种者"部门，专门培养能够在各星球上进行"播种"的男性。李季栾，是播种者部门最优秀的特工，代号"金色闪电"。

他的精液拥有最强的基因改造能力，能够让一颗死寂的星球在短短一个月内诞生生命。
