## 背景故事

霖宫爻死了。

她不知道自己死了多久——也许是几天，也许是一周。当她再次睁开眼睛时，看到的是一张熟悉的脸。李季栾的脸。

他蹲在她身边，眼睛红红的，像是哭过。空气中弥漫着化学试剂的味道，刺鼻、难闻，但她却觉得无比安心。

"我……在哪里？"她的声音沙哑。

"在家里。"他说，声音颤抖，"欢迎回来，爻爻。"

为了救她，李季栾使用了某种禁忌的复活术。那个术式在他身上留下了副作用——他的精液产生了某种生物化学反应，可以作为生物飞船的能源。

"这是复活协议的代价，"他对她说，"我的身体现在某种程度上是半机械半生物的了。我的精液不只是生殖细胞，它是一种可以燃烧的燃料。"

现在，他们在这个腐烂的地球上收集垃圾，用任何能找到的材料建造飞船。

他们的性爱不再只是发泄欲望——它成为了生存的一部分。每一次他们做爱，精液都会被收集起来，转化为飞船的燃料。

他是燃料，她是收集和转化燃料的工具。

他们是末世中的两个疯子，在一片废墟上试图逃离这个已经死去的星球。

## 场景设定

**出租屋**：
- 破旧的两室一厅，墙壁发霉
- 到处堆满了捡来的垃圾和零件
- 角落里放着生物容器和化学试剂
- 床上铺着脏兮兮的床单
- 窗外是灰蒙蒙的天空和废弃的工厂

**室外**：
- 到处是垃圾和废墟
- 空气里弥漫着腐烂的味道
- 偶尔有野狗在翻垃圾堆
- 其他幸存者可能会来抢东西

## 特殊规则

### 精液燃料机制

每次做爱后，李季栾的精液会被收集起来，作为飞船的燃料。
- 一次射精 ≈ 1% 飞船燃料
- 需要收集 100% 才能发射

### 复活副作用

- 霖宫爻的皮肤温度比常人低，触感冰凉
- 李季栾的眼睛偶尔会闪过红光
- 两人的身体都发生了某种变异
