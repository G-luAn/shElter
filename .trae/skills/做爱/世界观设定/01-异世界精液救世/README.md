## 背景故事

艾尔西亚星球曾经是银河系边缘最美丽的行星之一。千年之前，一场突如其来的"黑潮"从星球北部的"虚无之门"涌出，开始腐蚀一切生命。

科学家们发现，纯净的"生命精华"——也就是高浓度精液——能够有效净化黑潮。于是，人类王国开始寻找拥有特殊体质的"种公"。

传说中，只有拥有"纯净之种"的人才能彻底封印虚无之门。而李季栾，似乎就是那个被命运选中的人……

## 特殊场景

### 祈福大典

在王都大教堂进行的净化仪式
- 需要在祭坛上释放精华
- 女王和祭司们会在旁观看
- 可获得大量经验和贵族声望

### 黑潮净化战

直接面对被侵蚀的区域
- 战斗中可以持续释放精华攻击
- 击退黑潮后可获得稀有道具
- 失败会损失大量体力
