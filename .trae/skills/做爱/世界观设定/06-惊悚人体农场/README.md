## 背景故事

银河系边缘，有一颗被改造成巨大实验设施的行星——「伊甸-07」。这里曾是一个繁荣的殖民地，但在50年前，被一个神秘组织收购，改造成了「伊甸计划」的实验场。

「伊甸计划」的目标只有一个：通过培育最强壮的种公，提取精液中的「永生因子」，实现人类的永生。

李季栾的飞船在一次跃迁事故中迫降在这颗星球上。他发现，自己竟然是被选中的「S级完美实验体」……
