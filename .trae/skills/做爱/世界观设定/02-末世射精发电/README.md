## 背景故事

2077年，一场史无前例的"大停电"席卷全球。科学家发现男性精液中蕴含未知能量，可转化为电力。人类成立"最后一座城市"——新上海，将男性集中管理，编号为"行走的发电机"。

在这座5000万人口的超级都市里，精液不再只是生物液体，它可以被数字化、加密、交易。新上海分为三层：天空之城（精英）、地面城区（市民）、地下城（贫民）。

李季栾的飞船意外降落在这里，他发现这座城市的秘密远不止于此……
