## 背景故事

地球，浩瀚宇宙中一颗普通的蓝色星球。李季栾和霖宫爻就住在这里——某个人员密集的城市里，租着一间小小的出租屋。

他们的飞船还差得远呢。零件不够，钱不够，能源也不够。

所以，在飞船真正能飞之前，他们得：

- 去垃圾堆里翻零件
- 去各种奇奇怪怪的地方打零工
- 用李季栾的"特殊能力"赚点外快
- 当然，还有每天日常的嘿嘿嘿来维持能源储备

社死？那是什么？能吃吗？

反正等飞船造好了，他们就要去星际浪了。在那之前，在地球上的每一天都要过得刺激又充实！
