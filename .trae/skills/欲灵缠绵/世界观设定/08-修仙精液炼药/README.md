## 背景故事

在银河系的「仙道星域」，有一颗以「修仙」为核心的文明星球——「玄元星」。这里的修仙者不靠打坐冥想，而是以「精液炼丹」为主要修炼方式。

男性精液中蕴含的「元阳精华」，是天地间最纯净的能量。通过特殊的功法，修仙者可以将元阳精华提炼成「丹药」，从而突破境界、延长寿命、甚至飞升成仙。

李季栾的飞船在跃迁途中遭遇事故，迫降在玄元星。他被发现是罕见的「元阳之体」——精液中的元阳精华是普通人的百倍。顿时，整个星球的各大门派都想将他据为己有……
