## 背景故事

在"艾露提亚"魔法大陆，魔法共分为十二个系别。精液魔法是最强大也最神秘的系别。修炼者通过吸收和释放"生命精华"来提升魔力等级。

"艾露提亚魔法学院"是大陆上唯一教授精液魔法的学校。女生学习如何"吸收"精液魔力，男生则学习如何"释放"并控制自己的精液。
