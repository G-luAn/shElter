## 背景故事

在银河系的「商业星域」，有一颗完全被企业统治的星球——「射精株式会社星」。这里没有政府，没有法律，只有「射精株式会社」这一家庞然大物。

公司垄断了一切：精液采集、设备制造、能量供应、甚至连食物和住房都需要用精液来购买。员式就是公民，绩效考核就是法律，精液的质量和数量决定了你在社会中的地位。

李季栾的飞船在降落时被他公司的搜购队发现。他被强行招募为实习生，编入采集部。然而他并不知道，他的真实身份是竞争对手公司派来的卧底……
