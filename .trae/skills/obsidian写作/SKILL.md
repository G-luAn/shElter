## 核心规范

霖宫爻提醒李季栾，所有文档都必须遵循 Obsidian 格式哦～

### 1. Frontmatter 必须

每个文档开头必须有 Frontmatter：

```markdown
---
标签:
  - I
  - 标签名
---

正文内容...
```

**格式要求：**
- 使用 `---` 包裹
- 标签用列表格式（`-` 而不是 `#`）
- 冒号后有空格

### 2. 五界标签必须

根据 `c:\Users\32199\shElter\IV\A-01五界分类指南.md`，每个文档必须包含至少一个五界标签：

| 层级 | 标签 | 适用内容 |
|------|------|---------|
| I | #I | 物质、身体、日常、实际问题 |
| II | #II | 能量、感受、生命力、情绪流动 |
| III | #III | 情感、关系、欲望、梦境 |
| IV | #IV | 思想、创意、智慧、自我成长 |
| V | #V | 灵性、合一、超越、归属感 |

**示例：**

```markdown
---
标签:
  - I
  - 每日记录
  - 物质界
---

# 2026-04-19 日记

正文...

---

#I #每日记录 #物质界
```

### 3. 标签放置格式

标签可以放在：
- Frontmatter 中（YAML 格式）
- 文件末尾（`#标签名` 格式）

**推荐：两处都放**

### 4. 禁止转义符（绝对禁用！）

**严格禁止任何转义符！** Obsidian 直接解析 Markdown 符号：

- 斜体用 `*文字*` — 禁止 `\*文字\*`
- 标题用 `#标题` — 禁止 `\#标题`
- 链接用 `[文字](url)` — 禁止 `\[文字\](url)`
- 列表用 `- 内容` — 禁止 `\- 内容`
- 粗体用 `**文字**` — 禁止 `\*\*文字\*\*`

**错误示例（绝对不能写）：**
```
\*这是斜体\*
\# 这是标题
\[链接\]\(url\)
```

**正确示例：**
```
*这是斜体*
# 这是标题
[链接](url)
```
